Where the baseline comes from

Opening, facing-a-raise and small-blind charts are read cell-by-cell from the PokerCoaching.com full preflop charts (100bb, built for games with an ante). The PDF has no charts for limped pots, so the "Limpers" charts are a disciplined live-1/3 default written for this trainer: isolate with hands that win heads-up, overlimp hands that want a cheap multiway flop, fold the rest.

Common 1/3 adjustments: live opens are bigger ($12–$20) and there's no ante, so many players tighten the bluff 3-bets (blue) and some calls from early seats, and widen value isolations against loose limpers.
